# Outil de draft LoL

Outil de draft pour notre équipe : pools, compos, profils de champions, draft en direct et onglet « En jeu » (chronos des sorts d'invocateur adverses à la voix).

Ouvrir dans Chrome : https://axeloiu.github.io/outil-draft-lol/

- Au premier lancement, entrer le code d'équipe (partagé sur le Discord). Il relie les outils de tout le monde : pools, profils, draft et chronos sont synchronisés en direct.
- Onglet « En jeu » : cliquer sur le micro et autoriser Chrome. Exemples : « diana no flash », « mid no flash », « jungle no tp », « annule diana », « go ».

Outil de fan, non affilié à Riot Games. Rien ne touche au jeu : statistiques publiques, micro et saisie manuelle uniquement.
